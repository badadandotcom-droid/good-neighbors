## How-to that worked (adds to GNW Website 20's list)
- Checks: `npm ci` with `npm_config_noproxy=localhost,127.0.0.1` and the same NO_PROXY/no_proxy; `npx eslint . --ignore-pattern '.scratch/**'`; `npx tsc --noEmit -p .`; `npm run build`. Before copy: `git worktree add --detach .scratch/base HEAD`, `npm ci` and `npm run build` there, `npx next start -p 3001` (run_in_background); after copy on `-p 3000`; wait with `curl --retry 40 --retry-connrefused --retry-delay 1`. `node scripts/checks/crawl.mjs <dir> <url>` for both, then `compare.mjs`. Firstscreen from `<scratchpad>/tools` with a `node_modules/playwright-core` symlink to `$(npm root -g)/playwright` (a copy with the port changed to 3001 reads the before copy).
- Stop one local server only: find its PID with `ps aux | grep "[n]ext-server"` and `readlink /proc/<pid>/cwd`, then kill that PID and its npm parents. Never run `pkill -f "next start -p 3000"` in a command whose own text holds that string: it kills the shell (exit 144). `pkill -f "next[-]server"` stops both.
- Words-unchanged check: strip scripts, styles and `<a>` tags from both crawls, split on tags, diff the text lines per page.
- Phone before/after for Duane: Playwright 375 x 812 at deviceScaleFactor 2, then PIL side by side with "Before (live now)" and "After" labels; send with SendUserFile.
- Deploy wait: a background bash loop on `gh api repos/badadandotcom-droid/good-neighbors/commits/<sha>/statuses` picking the context that contains "good-neighbors", 10 s steps ("Vercel – wasp-problem: failure" shows on every push; not ours). It took about 20 s on Nov 2.
- Live read: load the built-in-browser skill, then ToolSearch "mcp__remote-devices__Claude_Browser__" (max 64); `preview_start` on a live page; one `javascript_tool` fetch with `cache: "no-store"` plus DOMParser (status, title, H1, robots, the line, its place before the Call button); `resize_window` preset mobile, navigate, screenshot at scale 0.5, then preset desktop. The shell cannot reach the live site (proxy 403), and WebFetch only takes URLs already seen in the chat (use WebSearch first).
