## Things learned in Parts 2–3 (save an hour)
- Workflow that works: build the CSV with the generator (claude/campaign-build-generator.py.md, `python3 -I campaign_build.py <region> <out_dir>`), preview the upload, apply, then check the result by script, not by eye.
- Login: account 832-908-5494 is under duane@goodneighborswildlife.ca, not the badadandotcom Gmail. ads.google.com/aw/campaigns?ocid=8516565077&authuser=1 opens it. In the built-in browser pane the account is already signed in; give the tab a 1440x1000 viewport (resize) so the tables are usable, and reset it to desktop when done.
- Bulk upload: Tools → Bulk actions → Uploads → + → "Upload a file" → file-upload tool on the "Select a file from your computer" input (find it with find) → Preview, then Apply. A new campaign needs an "EU political ads" column ("no"). The upload tool accepts files under /home/claude/.
- Campaign settings: "Campaign settings" link at the top of a campaign. Locations default to "All countries" after a bulk upload. Presence radio and Save are inside the Locations card; reach them with find.
- Ad group default bid: Ad groups table → click the "Default max. CPC" cell → a small "Max. CPC" box opens → select the value, type the new one → Save. Google shows "Your change has been saved."
- Ad schedule: /aw/adschedule?campaignId=... Add 7 rows. Time pickers ignore typing: open, press Down N times (15-minute steps: 5:30 PM = 70, 7:15 PM = 77), click the highlighted time. The list wraps at 96.
- Household income: Audiences overview → Demographics → Household income → Show table → Lower 50% → select all → Edit → Change bid adjustments → Decrease 30 → Apply. Direct URLs for demographics return 404; go through the menus.
- Shared negatives: attach via Keywords → Negative keywords → + → "Use negative keyword list". Add to the list via Tools → Shared library → Exclusion lists → GNW shared negatives → blue + → one per line → Save (the panel counts the entries before saving). The lists page shows the total.
- Assets: + → type → "Use existing" → tick by exact text → Save. The Toronto call asset shows as "4169009453".
- Keyword Planner (Tools → Planning → Keyword Planner → Get search volume and forecasts): the plan saves itself ("Plan from <date>"). Change location with the chip at the top; the location box ignores select-all, so clear it with form_input (value "") before typing the next town. There is no "York Region" target: use the towns. "Regional Municipality of Peel" and "Regional Municipality of Durham" exist. Month-by-month numbers per keyword are in the page's own BatchService/Batch network response (read_network_requests), 12 values per keyword running oldest → newest, so no download is needed. The bird plan is saved as "Plan from Oct 11, 2026, 8 PM" with the GTA locations.
- Typing while focus is outside a text box fires Google Ads shortcuts. Click inputs by ref first. Prefer find + ref over screen-position clicks (a stray click once opened a status menu; Escape closed it).
- Big tables only draw rows while painted: set scrollTop by script, take a tiny screenshot (scale 0.1), read rows. Don't use long JS scroll loops (one froze the tab).
- JS tool output is cut at about 1,000 characters; text with "&" can come back "[BLOCKED: Cookie/query string data]". Return counts and short lists.
- Negative-conflict check: load the shared negatives into a page variable (pages of 100), test each keyword (broad = all words present, phrase = in order, exact = equal), return only conflicts.
- The website chat's clock reads UTC ("Oct 12, early morning" = Oct 11 evening in Toronto). Log notes by the Toronto time Duane pasted them.
